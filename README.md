# 📊 Excel Dashboards Collection

This repository contains multiple interactive dashboards created using different datasets and built with Excel pivot tables, slicers, and charts.
Each dashboard provides insights into a specific domain and helps visualize key performance indicators (KPIs) in an easy-to-understand format.

## 📂 Dashboards
### 🟦 Sales Dashboard

Dataset: Sample sales data

Features: Revenue and profit trends, region/product-wise analysis, top customers, monthly & yearly sales

File: Sample_Sales_Data.xlsx

### 🟩 Health Dashboard

Dataset: Pakistan health data

Features: Key health indicators, region-wise comparison, public health trends, interactive KPIs

File: Pakistan_Health_Data Pivot table.xlsx

### 🟧 Pizza Sales Dashboard

Dataset: Pizza sales data

Features: Category-wise comparison with multiple fields (sales, quantity, revenue, etc.), trend analysis, KPIs for business performance

File: Pizza_Sales_Dashboard.xlsx

### 🟨 Education Dashboard

Dataset: Pakistan education data

Features: Enrollment trends, literacy rates, region-wise comparison, and student performance indicators

File: Pakistan_Education_Data Pivot table.xlsx

# 🚀 Tools Used

Microsoft Excel

Pivot Tables & Pivot Charts

Slicers and Filters for interactivity

# 🎯 Purpose

To demonstrate how Excel can be used to transform raw data into meaningful insights across different domains such as Sales, Healthcare, Food Industry, and Education
